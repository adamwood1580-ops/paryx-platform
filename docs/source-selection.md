# Prototype Source Selection

## Migrated into the new platform

- Paryx brand assets
- login and set-password flow
- protected-page bootstrap
- Supabase browser client
- profile/membership loader
- management dashboard
- member directory and status controls
- CSV member importer
- member invitation Edge Function
- generic club/course/member/booking/event/admin database schema reference
- shared design tokens/components

## Deliberately left behind

- all golfer scorecard pages and scoring engines
- hard-coded course data
- member home/play/profile experience
- member competition calendar UI
- member booking UI
- customer-specific logos, domains, seed records and weather data
- service worker / old PWA cache configuration
- diagnostics/dev-only pages
- duplicate/legacy booking frontend modules

The omitted functionality is not lost: the original prototype remains the reference for the future Paryx Member application.
