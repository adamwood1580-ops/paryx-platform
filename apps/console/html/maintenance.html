Temporary pre-release tool

Demo reset

Return the test platform to a clean demo state without removing club, course, tee-time or calendar configuration.

Destructive

Platform Owner required

Only a Platform Owner can preview or run the demo reset.

What this reset removes

Cleared
  • All Club Credit accounts and transactions
  • Competition entrants, results, prizes and result-import history
  • Player and visitor booking history
  • Player notifications and tee-time alerts
  • Member import / claim / access-request history
  • All non-demo club member records
  • All Paryx Auth accounts except the preserved demo owner
  • Development audit history
Preserved
  • Clubs and ClubHub configuration
  • Courses, tees, holes and tee-time inventory
  • Calendar events and competition definitions
  • Branding and module settings
  • Competition integration/device configuration
  • The preserved demo owner's staff/admin access

This is intentionally a temporary pre-release capability. It must be removed before the production release.
