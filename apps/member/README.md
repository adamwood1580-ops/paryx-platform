# Paryx Player

The Player app is the global golfer-facing Paryx experience.

## v0.26.0 capabilities

- Global Paryx account across multiple clubs.
- Visitor tee-time booking at any active Paryx club.
- Private self-service club membership linking using club + membership number + matching club-held email.
- My Clubs management and selected-club preference.
- Digital membership card and club information.
- Club calendar for linked memberships.
- Club Credit balances and transaction history.
- Confirmed competition results and member-highlighted leaderboards.
- Existing scorecard / Play entitlement model.

ClubHub never receives the Player↔membership link state. Clubs manage their own member records; Paryx privately handles global Player identity.
